# Изменения MuseDPI Desktop

## 0.1.0-alpha.3

- Flowseal 1.10.4: четыре проверенные UDP-приманки с ручным выбором, до 12 повторений.
- Ручной импорт полного IP-набора Flowseal (33 336 записей), лимиты 50 000 записей / 2 МиБ.
- Восемь TCP/TLS-профилей ByeDPI; единый список ID для интерфейса и проверки настроек.
- Отчёт по каждой стратегии, сохранение частичных результатов после отмены.
- Если победил уже работающий профиль, автоподбор не перезапускает основной прокси.
- Дополнены домены Discord: discord.media и discordcdn.com.
- Новые UDP/IP-правила не включаются автоматически. winws/WinDivert не эмулируются.

## 0.1.0-alpha.2

- Постоянный настраиваемый порт SOCKS5: по умолчанию 1080. Миграция настроек alpha.1 без потери правил.
- Автоподбор в отдельном временном прокси: рабочее подключение сохраняется до применения победителя.
- Отмена автоподбора и HTTP-проверок, прогресс этапов, последовательное появление результатов.
- Повторная проверка тех же сервисов перед применением и на основном порту; откат при ошибке запуска, проверки или сохранения.
- Понятные ошибки HTTP, DNS, TLS, таймаута и отсутствующего curl вместо одинакового сообщения.
- Компактный режим с сохранением выбора и кнопка desktop-релизов в помощи.
- Загрузка интерфейса не зависит от рабочей папки ярлыка. Повторный запуск восстанавливает свёрнутое окно.

После обновления один раз укажите в SOCKS-клиенте новый постоянный порт вместо случайного.
Это по-прежнему alpha: системного туннеля и автоматической установки обновлений нет,
UDP для игр экспериментальный. Проверки HTTP не доказывают работоспособность звонков и игр.
