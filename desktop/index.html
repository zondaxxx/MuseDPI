Игровой фильтр

Дополнительный обход по портам назначения, независимо от выбранных сервисов.

Игровые правила

Первый TCP-запрос разбивается на части. До 56 портов суммарно для TCP и UDP: значения или диапазоны через запятую.

UDP-фейки могут нарушить соединение. Оставь поле пустым, если нужен только TCP. Игра должна использовать SOCKS5 UDP.

В режиме «Только IP-набор» фильтр ограничен адресами набора. UDP поддерживает один адрес назначения на SOCKS-ассоциацию. Запущенные игры автоматически не определяются.

Стратегии

Способ обработки HTTP и TLS для выбранных сервисов и IP-наборов.

Стратегия обхода

Проверим четыре стратегии по выбранным Discord и YouTube. Подбор перезапускает прокси; игровые соединения он не проверяет.

Как подключиться

  1. Запусти локальный прокси

    Выбери сервисы и стратегию, сохрани настройки и нажми «Подключить».

  2. Укажи адрес в приложении

    В настройках Firefox выбери ручной прокси SOCKS5, адрес 127.0.0.1 и порт с экрана подключения. Включи DNS через SOCKS5.

  3. Проверь сервисы

    Время отклика измеряется реальным HTTP-запросом. Проверка сайта не подтверждает работу звонка, видео или игровой сессии.

Что охватывают правила

Только трафик, который приложение направило в SOCKS5. MuseDPI Desktop не меняет системный VPN, маршруты и страну подключения. Для игр без SOCKS понадобится отдельная маршрутизация трафика.

Настройки и перезапуск

Настройки сохраняются на этом компьютере. Их применение при активном подключении перезапускает только прокси MuseDPI. Порт сохраняется до выхода из приложения.
