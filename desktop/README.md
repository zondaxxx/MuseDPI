# MuseDPI Desktop · 0.1.0-alpha.1

Ранняя тестовая версия для Windows x64: [скачать alpha-релиз](https://github.com/zondaxxx/MuseDPI/releases/tag/desktop-v0.1.0-alpha.1).

Windows x64: локальный SOCKS5, четыре встроенных профиля, автоподбор,
HTTP-проверки Discord и изображения YouTube, время последней проверки.
Интерфейс с разделами подключения, сервисов, IP-наборов, игрового фильтра и стратегий.
Нет системного туннеля, установки драйверов, автозапуска или изменения настроек сети.
Подписанный мобильный онлайн-каталог пока не подключён: Windows-прототип использует
обычное ядро ByeDPI 0.17.3 без специфичных патчей мобильной сборки.

## Windows

Распакуйте **всю** папку `MuseDPI-win32-x64` и запустите `MuseDPI.exe`.
Выберите профиль и нажмите «Подключить». Скопируйте показанный адрес SOCKS5
в приложение с поддержкой прокси, включите DNS через SOCKS.
Например, Firefox: ручная настройка прокси, SOCKS Host `127.0.0.1`, порт с экрана,
SOCKS v5 и «Proxy DNS when using SOCKS v5».

Закрытие приложения останавливает только его собственное ядро. Порт выбирается
автоматически при первом подключении и сохраняется при смене стратегий.
После перезапуска приложения порт может измениться — обновите его в клиенте.
Для диагностики нужен `curl.exe` из современной Windows.

**Ограничения:** приложения без SOCKS, QUIC/HTTP3 и системный трафик не охватываются.
HTTP-ответ не доказывает работоспособность видеопотока, голосовых звонков или обхода DPI
в вашей сети. Прототип не скрывает IP и не меняет страну.
Сборка не подписана Authenticode; при предупреждении Windows не обходите его автоматически.

## Правила трафика

- **Сервисы:** Discord, YouTube, Telegram Web, Twitch, Steam и Roblox; можно добавлять
  свои домены и исключения. Доменные наборы — стартовые списки, а не полный реестр
  инфраструктуры каждого сервиса. Для четырёх дополнительных сервисов встроенного
  HTTP-теста нет; приложение не показывает выдуманный отклик.
- **IP-наборы:** IPv4/IPv6 и CIDR, вставка текста или импорт `.txt`, `.cidr`, `.list`.
  До 5000 записей и 512 КБ на файл, комментарии после `#`. Импорт добавляет записи
  в черновик; применение происходит только после сохранения.
  «Сервисы и IP-набор» объединяет области обработки (ИЛИ). «Только IP-набор»
  отключает доменные правила и ограничивает также игровой фильтр указанными IP.
  Исключения IP всегда имеют приоритет. Исключения доменов действуют для HTTP/TLS,
  где ядро может определить имя сервиса. IPv4-наборы автоматически дополняются
  IPv4-mapped IPv6-записями, которые ядро использует для UDP.
- **Игровой фильтр:** отдельные TCP/UDP-порты назначения; по умолчанию выключен.
  TCP делит первый запрос в позиции 1. UDP отправляет указанное число фейков
  с выбранным TTL и является экспериментальным: может мешать игровому протоколу.
  Пустое поле UDP оставляет UDP без обработки. Работает только с трафиком,
  уже направленным в SOCKS5; процессы игр не определяются и не перенаправляются.
  До 56 портов суммарно для TCP и UDP (лимит числа групп ядра). Диапазоны компилируются в отдельные точные порты,
  чтобы не зависеть от сравнения диапазонов в сетевом порядке байтов в ядре 0.17.3.
  Одна SOCKS UDP-ассоциация ядра поддерживает один адрес назначения.
- **Сохранение:** настройки хранятся в `settings.json` в Electron userData.
  При применении во время работы перезапускается только собственный прокси;
  при неудаче запуска восстанавливаются предыдущие правила. Чужие VPN не меняются.

Временные списки передаются ядру через файлы и удаляются после остановки.
Остальной трафик проходит без DPI-модификаций. При пустом выборе сервисов,
отключённых IP-наборах и игровом фильтре прокси работает без обхода.
Настройки ядра соответствуют [документации ByeDPI](https://github.com/hufrea/byedpi/blob/v0.17.3/README.md).

## Разработка и сборка

```sh
cd desktop
npm ci
npm test
npm run engine:windows
npm run package:windows
```

Для локального теста на Mac положите отдельно собранное ядро в `desktop/engine/ciadpi`
и выполните `npm start`. Проверка реальных HTTP-ответов: `npm run smoke`.
Она использует текущее подключение компьютера и не выключает чужой VPN.
Проверка интерфейса на Mac не является проверкой Windows executable.

Windows-ядро загружается из официального релиза
[hufrea/byedpi v0.17.3](https://github.com/hufrea/byedpi/releases/tag/v0.17.3).
SHA-256 архива зафиксирован в `scripts/prepare-engine.mjs` и проверяется до распаковки.
Лицензии MuseDPI и ByeDPI включены в комплект; исходники оболочки находятся здесь,
исходники используемого ядра — в указанном релизе upstream.

Renderer изолирован от Node.js и shell, загрузка удалённых страниц и разрешения
запрещены, команды IPC проверяются; основа —
[рекомендации безопасности Electron](https://www.electronjs.org/docs/latest/tutorial/security).
