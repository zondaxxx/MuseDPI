# MuseDPI · iOS 0.4.8 / Android 0.5.1

- Новый морской дизайн, логотип «m», иконки и название MuseDPI.
- Компактный главный экран: состояние подключения и отклик сервисов видны раньше.
- Быстрые HTTP-проверки не ждут загрузку 256 КБ. Полная диагностика и подбор стратегий сохраняют проверку загрузки и зависания потока.
- Время последней проверки помогает отличать свежие результаты от старых.
- Улучшена читаемость настроек iPhone; основные кнопки учитывают уменьшение движения.
- Описания подключения учитывают выбранные сервисы, а не только Discord и YouTube.
- Android ограничивает размер загрузки каталога во время чтения ответа.

## Установка

Android: `MuseDPI-0.5.1-universal-release.apk` для большинства устройств, либо APK нужной архитектуры. Подпись и applicationId сохранены: можно обновить прежнюю PalkaDPI без удаления данных.

iOS: `MuseDPI-0.4.8-unsigned.ipa` не подписана. Для установки нужна собственная подпись с поддержкой Network Extension и App Groups; обычная установка неподписанной IPA не работает. Идентификаторы приложения и App Group сохранены.

Контрольные суммы файлов опубликованы вместе со сборками. Старые релизы и их файлы не заменены.

MuseDPI обрабатывает трафик локально, не скрывает IP и не меняет страну. Доступность зависит от сети и выбранной стратегии; тесты в эмуляторе не подтверждают работу в LTE.
