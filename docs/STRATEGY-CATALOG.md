# Подписанный каталог стратегий

Каталог находится в корне репозитория:
[`strategy-catalog.json`](../strategy-catalog.json). Его отделённая Ed25519-подпись:
[`strategy-catalog.json.sig`](../strategy-catalog.json.sig). Приложение принимает
обновление только после проверки подписи встроенным публичным ключом.

## Добавление стратегии

1. Создайте уникальный стабильный `id` и увеличьте `generation` каталога.
2. Добавьте английские поля и, по возможности, `nameRu`, `summaryRu`,
   `stabilityRu`.
3. Укажите поддерживаемые `services`, минимальные версии приложения/ядра и
   HTTPS-ссылку `sourceURL`.
4. В `commandArgs` передавайте каждый аргумент отдельной JSON-строкой.
5. Используйте `{palka_targets}`: приложение подставит домены выбранных сервисов
   и пользовательские домены.
6. Для снятия стратегии с распространения добавьте её `id` в `revokedStrategyIDs`.
   Для мягкого предупреждения используйте `deprecated: true`.
7. Проверьте, подпишите и повторно проверьте каталог:

```bash
swift scripts/validate_strategy_catalog.swift strategy-catalog.json strategy-catalog.json.sig

PALKA_CATALOG_PRIVATE_KEY=/secure/path/catalog-ed25519-private.pem \
  ./scripts/sign_strategy_catalog.sh strategy-catalog.json strategy-catalog.json.sig

swift scripts/validate_strategy_catalog.swift strategy-catalog.json strategy-catalog.json.sig
```

Приватный ключ никогда не добавляется в репозиторий. Владелец релиза хранит его
отдельно; публичный ключ зафиксирован в приложении и валидаторе.
Скрипт подписи проверяет результат встроенным ключом доверия перед заменой
файла подписи. Неподходящий приватный ключ не повредит действующий каталог.

## Поколение 7 · 12 ноября 2026

Каталог сохраняет 13 существующих стратегий и добавляет четыре экспериментальных
профиля для обеих платформ: мягкое разбиение SNI, разбиение в середине SNI,
TLS-запись в середине SNI и TLS-запись на границе SNI. В каждом профиле TLS и HTTP
разделены по протоколам, применяются только к выбранным доменам, а прочий трафик
проходит без модификаций. Рабочий пресет автоматически не заменяется.

Параметры сверены с [документацией ByeDPI 0.17.3](https://github.com/hufrea/byedpi/blob/v0.17.3/README.md)
и проверены запуском встроенного ядра с SOCKS5-рукопожатием. Это проверяет
синтаксис и запуск, но не доказывает обход DPI в сети конкретного оператора.
TLS-record-профили могут быть несовместимы с отдельными сетевыми устройствами.

Проверка кандидатов с отдельно собранным исполняемым файлом ядра:

```bash
python3 scripts/test_strategy_candidates.py /path/to/patched-ciadpi strategy-catalog.json
```

Скрипт проверяет запуск всех активных записей, а не только новых кандидатов.
Нужно встроенное patched-ядро с поддержкой `hex:`, не обычный desktop executable.
Это не проверка голосового UDP или диапазонов портов на реальном устройстве.

UDP-приманки старых Flowseal-профилей сверены с релизом **1.10.4** и снимком
`2401b7a13837139b0265632464ba563dddbf80d8`: Google QUIC и Discord побайтно не изменились.
В каталоге уточнены происхождение и ограничения; старые команды не заменены
несовместимыми winws-флагами. Новые четыре профиля не добавляют глобальную обработку UDP.
Подробнее: [совместимость Flowseal](./FLOWSEAL-COMPATIBILITY.md).

Для следующей публикации сначала подпишите JSON **исходным ключом доверия**
в отдельный файл подписи и проверьте валидатором. Только после успешной проверки
замените оба действующих файла и опубликуйте их вместе. Подпись от другого ключа
приложение отвергнет; отключать проверку или менять ключ для старых клиентов нельзя.

## Что проверяется

- схема версии `2`, монотонное поколение и не более 100 стратегий;
- Ed25519-подпись точных байтов JSON до декодирования;
- защита от загрузки поколения старее уже проверенного кэша;
- совместимость `minimumAppVersion` и `minimumEngineVersion`;
- уникальность ID и отсутствие записи в `revokedStrategyIDs`;
- размер каталога до 512 КиБ, до 160 аргументов на стратегию;
- HTTPS для `sourceURL`, отсутствие NUL/CR/LF и ограничение длины аргументов;
- совместимость команды со встроенным Apple-валидатором `SBDConfig`.

Форк ядра MuseDPI дополнительно поддерживает `-k`/`--udp-drop` (группа вида
`-Ku -V443 --udp-drop -An` молча сбрасывает QUIC, приложение добавляет её само при
включённом переключателе «Блокировать QUIC») и для неисполняемых бинарных
UDP-приманок `-l hex:<данные>`. Один аргумент ограничен 4096 символами, поэтому payload
должен быть не больше 2046 байт. Источник, лицензия и SHA-256 таких данных
обязательны в `THIRD_PARTY_LICENSES/`. Патчи ядра лежат в `patches/byedpi/`.

Каталог не запускает shell-команды и не загружает исполняемые файлы. Профили с
WinDivert, `--fake`, raw packet injection или файлами Windows zapret отклоняются.

## Офлайн и откат

После успешной проверки приложение сохраняет до трёх поколений каталога в
App Group. При сетевой ошибке используется последний проверенный кэш. Пользователь
может выбрать предыдущее поколение на экране каталога; неподписанный или
несовместимый кэш никогда не применяется.
