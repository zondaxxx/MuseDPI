# Flowseal и MuseDPI: что переносится

Проверено **12 ноября 2026**. Последний релиз upstream —
[1.10.4](https://github.com/Flowseal/zapret-discord-youtube/releases/tag/1.10.4),
опубликован 20 октября 2026. Данные зафиксированы на
[коммите 2401b7a](https://github.com/Flowseal/zapret-discord-youtube/tree/2401b7a13837139b0265632464ba563dddbf80d8)
от 4 ноября 2026, включающем обновление IP-набора после релиза.

## Desktop alpha.3

- Четыре оригинальные UDP-приманки: Game, Discord, QUIC Google и QUIC Steam Chat.
  Это не исполняемый код; каждая проверяется по размеру и SHA-256 перед использованием.
  ByeDPI получает двоичный временный файл через `-l`, без необходимости мобильного `hex:`-патча.
- По умолчанию остаётся стандартная приманка, игровой фильтр выключен, UDP-порты пусты.
  Выбор Flowseal **не добавляет порты** и не перенаправляет игры в SOCKS.
  Для обработки UDP/443 нужно явно указать 443. Режим «Только IP-набор» ограничивает
  обработку по адресам; IP-исключения приоритетны. Доменные исключения работают для HTTP/TLS, не UDP.
- Повторения UDP: 1–12, TTL: 1–32. Значения не копируются автоматически из BAT.
  TTL и приманки могут нарушить протокол или доходить до сервера; это экспериментальная настройка.
- Снимок IP-набора содержит **33 336 записей**. Использован `lists/ipset-all.txt.backup`:
  обычный `ipset-all.txt` содержит только отключающий маркер `203.0.113.113/32`.
  Встроенная gzip-копия распаковывается с ограничением размера и проверкой SHA-256.
  Импорт добавляет набор в черновик, не включает режим и не сохраняет настройки автоматически.
  Это широкий upstream-набор, а не точный список выбранных сервисов; нужна проверка перед применением.

Восемь TCP/TLS-профилей desktop — стратегии **ByeDPI 0.17.3**, не копии Flowseal BAT.
`hostfakesplit`, `split-seqovl`, `fooling=ts`, TCP fake injection и фильтрация Discord/STUN
по L7 из winws не эмулируются. WinDivert, службы, драйверы и права администратора не добавлены.
Автоподбор измеряет HTTP только, не сравнивает UDP-приманки и не проверяет игровые сессии.

## Мобильный каталог

Поколение 7 добавляет четыре общих TLS/HTTP-кандидата с раздельными протокольными группами.
Старые Flowseal-производные записи сохранены, их источники закреплены и ограничения уточнены.
Google QUIC (`f4589c57…`) и Discord (`2fe18b3b…`) остались побайтно прежними:
смена версии upstream сама по себе не является изменением этих приманок.
Новые desktop Game/Steam-приманки не добавляются в мобильный каталог автоматически.

## Проверяемость

Метаданные, полные хеши и неизменённые данные: `desktop/data/flowseal.json`.
Атрибуция и MIT-лицензия: `THIRD_PARTY_LICENSES/Flowseal-zapret.txt`.
Native-тесты проверяют точные байты UDP-приманок, число пакетов, выбранные порты,
IP-исключения, запуск с полным IP-набором и очистку временных файлов.

Эти проверки не доказывают обход блокировок: домашняя и мобильная сеть РФ, звонки,
игры, видео и устойчивость сессий требуют отдельного тестирования на конкретной сети.
Чужие VPN при проверках не отключаются.
